# Gunfighters Studio Website

총잡이 스튜디오 공식 웹사이트 / Official website for Gunfighters Studio

A Hugo-powered website showcasing our video game studio, featuring:

- **Landing Page** - Introduction to Gunfighters Studio
- **Showcase** - Portfolio of our games and projects
- **Contact** - Get in touch with our team

## Development

### Prerequisites

- [Hugo](https://gohugo.io/) (Extended version recommended)

### Running Locally

```bash
hugo server -D
```

Then open [http://localhost:1313](http://localhost:1313) in your browser.

### Building for Production

```bash
hugo
```

The site will be generated in the `public/` directory.

## Theme

This site uses a custom theme (`gunfighters-theme`) designed specifically for the studio's branding.
