# Gunfighters Theme

A dark, modern Hugo theme designed for video game studios and gaming portfolios.

## Features

- Dark theme with red accent colors
- Responsive design for mobile and desktop
- Game showcase cards with status badges
- Contact form with styled inputs
- Feature grid for highlighting services
- Clean typography and modern aesthetics

## Installation

Add this theme to your Hugo site's `themes` directory:

```bash
cd your-hugo-site/themes
git clone https://github.com/Gunfighters/Gunfighters.github.io gunfighters-theme
```

Then add the theme to your `hugo.toml`:

```toml
theme = 'gunfighters-theme'
```

## Configuration

Configure your site in `hugo.toml`:

```toml
[params]
  description = "Your studio description"
  tagline = "Your tagline"
  email = "contact@yourstudio.com"
```
